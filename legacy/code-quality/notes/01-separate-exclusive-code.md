# Exercise 01 학습 기록

## 학습 질문

배달과 매장 픽업처럼 동시에 실행되지 않는 두 흐름을 어느 경계에서 분리해야 하는가?

## 초기 이해

실습을 시작하기 전에 현재 생각을 작성한다.

## 관찰 가능한 요구사항

- 배달을 선택하면 배달 주소만 입력한다.
- 매장 픽업을 선택하면 픽업 매장만 입력한다.
- 필요한 값이 없으면 현재 흐름에 맞는 안내를 보여준다.
- 성공하면 선택한 수령 방법에 맞는 결과를 보여준다.

## 선택한 설계

구현 후 어떤 책임을 유지하거나 분리했는지와 그 이유를 작성한다.

## 검토한 대안과 트레이드오프

선택하지 않은 구조가 있었다면 장점과 비용을 함께 작성한다.

## 추가된 변경 요구사항

첫 구현과 리뷰가 끝난 뒤 추가한다.

## 실제로 변경된 범위

변경된 파일과 각 파일이 바뀐 이유를 작성한다.

## 잘못 이해한 부분

처음의 전제 중 코드와 변경을 통해 수정된 내용을 작성한다.

## 최종적으로 배운 점

다음 코드에서 재사용할 수 있는 판단 기준을 자신의 말로 작성한다.
