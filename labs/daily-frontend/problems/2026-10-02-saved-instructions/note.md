# 풀이 기록

## 어떤 값이 저장의 원본이고, 어떤 값이 편집 중인 값인가요?

저장의 원본:

- `publishedText`: 현재 공개된 안내

편집 중인 값:

- `draftText`: 거래 안내 초안

## 저장 대기·실패·성공에서 각 값과 조작은 어떻게 달라져야 하나요?

대기:

- 거래 안내 초안에 공백만 있을 경우 즉시 종료
- 로딩중 처리

실패:

- `저장하지 못했어요. 다시 시도해 주세요.` 안내 문구 표시
- 저장 결과 "에러" 처리
- 로딩 처리가 끝난 상태

성공:

- `거래 안내를 저장했어요.` 안내 문구 표시
- 저장 결과 "성공" 처리
- 로딩 처리가 끝난 상태
- 공개된 안내를 거래 안내에 입력한 텍스트로 변경
