## SEED 확인과 한계

- 설치 React 2.5.1 / CSS 2.8.3. React의 CSS peer `^2.8.0`과 일치합니다. 기존 공식 RadioGroup/TextField/ActionButton 스니펫의 요구 버전과 공개 props·콜백 타입, Callout 공개 파츠를 확인했습니다. TextField 콜백은 `{ value }`, RadioGroup은 문자열입니다.
- 역할별 대응은 `problem.md`에 기록했습니다. 공식 컴포넌트가 있는데 native 컨트롤로 대신한 예외는 없습니다. CSS는 페이지 내 최소 터치 높이에만 사용하고 여백은 공개 레이아웃 props를 사용합니다.
- AUTHORING의 외부 자료 금지 규칙을 우선해 외부 SEED 인덱스·공통 디자인 문서·최신 React 문서·registry 기반 CLI compat는 조회하지 않았습니다. 설치본의 타입/스니펫/peer와 실제 렌더 검증만 완료했으며, 최신 공식 문서 대조까지 완료했다고 주장하지 않습니다. 이 미확인 범위를 표시해 Draft PR로 제출합니다.
- 실제 파일 생성/다운로드, 실기기, 모든 브라우저·키보드·스크린리더 조합과 시각 회귀 테스트는 검증하지 않았습니다. HTTP 접수까지만 있는 학습 화면입니다.
