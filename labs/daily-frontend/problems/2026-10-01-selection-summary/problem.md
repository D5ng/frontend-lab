# 2026-10-01 · 선택한 항목은 몇 개일까?

- 유형: 작은 기능 구현 · 파생값 판단
- 예상 시간: 15분

## 사용자 목표

저장한 상품 목록에서 삭제할 항목을 선택하는 사용자가 선택 개수와 삭제 가능 여부를 바로 확인할 수 있어야 합니다.

## 오늘의 범위

`Problem.tsx`에 실행할 화면이 준비되어 있습니다. 오늘은 목록을 받아 화면에 필요한 두 값을 반환하는 `getSelectionSummary` 함수만 구현합니다. 비동기 요청이나 React Effect는 다루지 않습니다.

[`starter.ts`](./starter.ts)의 각 상품에는 선택 여부인 `isSelected`가 있습니다. 함수는 다음 정보를 반환해야 합니다.

- `selectedCount`: 선택된 상품의 개수
- `canDelete`: 선택된 상품이 하나 이상일 때 `true`

## 완료 조건

1. 선택된 상품이 두 개이면 `{ selectedCount: 2, canDelete: true }`를 반환합니다.
2. 선택된 상품이 없거나 목록이 비어 있으면 `{ selectedCount: 0, canDelete: false }`를 반환합니다.
3. 전달받은 목록과 각 상품의 선택 여부를 변경하지 않습니다.

## 생각할 질문

> 목록의 `isSelected`가 바뀔 때 이 함수를 다시 호출할 수 있다면, 선택 개수와 삭제 가능 여부도 각각 별도의 상태로 저장할 필요가 있을까요? 이유를 한 문장으로 적어보세요.

## 푸는 순서

1. 먼저 선택 개수를 구하는 부분을 구현합니다.
2. 그 개수를 이용해 삭제 가능 여부를 결정합니다.
3. 선택 0개, 1개, 2개와 빈 목록을 직접 넣어 보거나, 각각의 예상 반환값을 기록합니다.

루트에서 `pnpm dev:daily`를 실행하고 해당 문제를 선택하세요. 화면에서 상품 선택을 바꾸며 함수의 반환값이 어떻게 표시되는지 확인할 수 있습니다. 빈 목록은 상품을 모두 선택한 뒤 삭제해서 확인합니다.
