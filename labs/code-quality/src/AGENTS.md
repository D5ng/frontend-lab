# Code Quality Lab Source Rules

`src/`에 새 예제 코드, 테스트, 또는 학습용 스니펫을 작성할 때는 deprecated 상태인 API, React 기능, 패키지, 패키지 export를 사용하지 않는다.

- 현재 설치된 패키지 버전과 공식 문서에서 지원되는 대안을 우선 사용한다.
- deprecated 여부가 불확실하면 추측으로 예제를 만들지 말고, 해당 패키지의 타입 선언 또는 공식 문서에서 확인한 뒤 작성한다.
- 기존 코드에 deprecated 사용이 발견되면, 새 예제에서 이를 복제하거나 확장하지 않는다. 교체가 요청 범위에 포함되었을 때만 지원되는 대안으로 바꾸고, 동작 차이가 있으면 학습 노트 또는 변경 설명에 기록한다.
- 이 규칙은 표현 방식의 취향이 아니라 학습 예제의 정확성을 위한 필수 조건이다.
