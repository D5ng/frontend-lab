# Exercise 03 디자인 방향

## 제품 인상

`하루`는 거창한 생산성 도구가 아니라 생활 약속을 잊지 않게 돕는 모바일 앱이다. 화면은 친근하되 장식적이지 않고, 사용자가 남은 일과 다음 행동을 빠르게 찾을 수 있어야 한다.

토스나 당근 같은 국내 모바일 제품에서 참고하는 것은 브랜드 표현이 아니라 다음 원칙이다.

- 첫 화면에서 가장 중요한 숫자와 행동이 바로 보인다.
- 문장은 짧고 사용자의 언어로 쓴다.
- 누를 수 있는 것과 읽기만 하는 정보를 명확하게 구분한다.
- 빈 상태와 완료 결과에서도 다음 상황을 이해할 수 있다.

## 시각 체계

Montage의 light theme 토큰을 화면의 기본 언어로 사용한다.

- `semantic.primary.normal`: 주요 진행 상태와 결과 안내
- `semantic.label.normal`: 제목과 핵심 정보
- `semantic.label.alternative`: 날짜, 장소 같은 보조 정보
- `semantic.line.solid.alternative`: 목록 항목의 구분
- `semantic.background.normal.alternative`: 앱 바깥의 캔버스
- `semantic.accent.foreground.*`: 생활 카테고리 배지

타이포그래피는 Montage `Typography`의 variant와 weight로 위계를 만들고, Pretendard와 시스템 한글 글꼴은 그 기반으로만 사용한다.

## 레이아웃

```text
┌─────────────────────────────┐
│ 하루                        │
├─────────────────────────────┤
│ 역삼동의 생활               │
│ 오늘도 차근차근             │
│ 9월 18일 목요일             │
├─────────────────────────────┤
│ 오늘 남은 일 2개       50%  │
│ 할 수 있는 만큼, 하나씩     │
│ ━━━━━━━━━╺━━━━━━━━          │
├─────────────────────────────┤
│ 나의 할 일        완료 정리 │
│ [ 할 일을 검색해 보세요   ] │
│ [전체 4] [할 일 2] [완료 2]│
│ ✓ 생활  분리수거함 내놓기   │
│   오늘 오후 8시 · 우리 집   │
│ ✓ 건강  반려견 예방접종     │
│   내일 오전 10시 · 병원     │
└─────────────────────────────┘
```

상단 요약 표면 하나만 경계와 그림자로 구분한다. 목록은 카드가 반복되는 대신 Montage의 구분선과 충분한 여백으로 이어져, 정보가 많은 화면에서도 한 흐름으로 읽히게 한다.

## 상호작용 기준

- 완료 버튼과 필터에는 선택 상태가 색 외의 형태로도 드러난다.
- 포커스 링을 제거하지 않는다.
- 진행률 변화에는 장식적인 자동 애니메이션을 추가하지 않는다.
- 비활성화된 정리 버튼은 누를 수 없다는 사실이 명확해야 한다.
- 결과 메시지는 보조 기술에서도 알 수 있도록 live region으로 제공한다.

## 학습 범위와의 관계

UI를 실제 제품처럼 만드는 이유는 예쁜 예제를 만들기 위해서만이 아니다. 진행 카드, 필터 개수, 목록, 빈 상태처럼 하나의 원본에서 파생되는 소비자가 여러 곳에 있을 때, 상태 설계의 결과가 사용자 화면에 어떻게 전파되는지 관찰하기 위해서다.
