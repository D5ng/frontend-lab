# 필라테스 수업 예약

- 역할: 적용 · 30분
- 유형: 리팩터링. 동작하는 시작 코드와 이미 통과하는 행동 테스트가 있습니다.
- 도메인: 예약 (필라테스 스튜디오의 그룹 수업)
- SEED: `Avatar`(`seed-design/ui/avatar`), `Badge`, `List` + `ListItem` · `ListButtonItem` · `ListHeader`, `BottomSheet`, `Callout`, `Skeleton`, `ActionButton`, `Snackbar`

```bash
pnpm dev
pnpm --filter @frontend-lab/drills test problems/2026-11-02-abstraction-level/problem-2
```

## 화면

> 스튜디오 회원이 이번 주 수업 하나를 열어 보고, 가진 수강권으로 그 자리에서 예약한다.

```text
수업 예약 (한 화면) → 수강권 고르기 (바텀시트)
```

- 수업 목록에서 이 화면으로 들어왔다고 보고, 목록은 이번 범위가 아닙니다.
- 수강권은 바텀시트에서 고릅니다. 값 하나를 고르는 일이고, 닫아도 잃을 것이 없기 때문입니다. 고르는 즉시 시트가 닫히고 반영됩니다.
- 취소 규칙은 화면에 남아 있어야 하는 안내라서 `Callout`으로 둡니다.
- 예약 결과는 버튼 자리에 남고(`예약한 수업이에요`), 잠깐 뜨는 `Snackbar`로도 알립니다.

## 규칙

- 남은 자리는 정원에서 예약 인원을 뺀 값입니다. 1~2자리 남으면 `마감 임박`을 붙이고, 0자리면 `자리가 모두 찼어요`라고 쓰고 예약할 수 없습니다.
- 다 쓴 수강권(남은 횟수 0)과 수업 전에 기간이 끝나는 수강권은 이 수업에 쓸 수 없습니다. 시트에는 보이지만 고를 수 없고, 이유를 보여 줍니다.
- 처음에는 이미 예약한 수강권, 없으면 이 수업에 쓸 수 있는 첫 수강권이 골라져 있습니다. 쓸 수 있는 수강권이 하나도 없으면 예약할 수 없습니다.
- 수업 시작 4시간 전(`cancelDeadlineHours`)까지 취소하면 수강권 1회가 돌아옵니다. 그 기한을 `11월 4일 (수) 오후 3:00`처럼 보여 줍니다.

| 상태     | 보여 주는 것                                                                |
| -------- | --------------------------------------------------------------------------- |
| 불러오기 | 수업 정보 자리에 `Skeleton`                                                 |
| 실패     | 불러오기 실패는 `Callout`과 `다시 불러오기`. 예약 실패는 `Snackbar`         |
| 빈 상태  | 쓸 수 있는 수강권이 없으면 수강권 자리에 이유를 쓰고 예약 버튼을 잠근다     |
| 비활성   | 예약하는 동안 예약 버튼과 수강권 바꾸기를 함께 잠근다. 자리가 없어도 잠근다 |
| 성공     | `Snackbar`로 알리고, 버튼이 `예약한 수업이에요`로 바뀐다                    |

## 모의 API

모의 서버(`handlers.ts`)는 풀이 대상이 아닙니다. 응답 타입과 요청 함수는 `api.ts`에 있습니다.

```http
GET /api/drills/2026-11-02/classes/mat-1104-1900
```

```json
{
  "gymClass": {
    "id": "mat-1104-1900",
    "name": "매트 필라테스 중급",
    "startsAt": "2026-11-04T19:00:00+09:00",
    "durationMinutes": 50,
    "capacity": 8,
    "bookedCount": 6,
    "waitlistCount": 0,
    "cancelDeadlineHours": 4,
    "myBooking": null,
    "...": "스튜디오, 강사"
  },
  "passes": [
    { "id": "group-10", "name": "그룹 10회권", "remainingCount": 7, "expiresAt": "2026-12-31T23:59:59+09:00" },
    "... 모두 4개. 다 쓴 것 하나, 수업 전에 끝나는 것 하나"
  ]
}
```

```http
POST /api/drills/2026-11-02/classes/mat-1104-1900/bookings
{ "passId": "group-10" }
```

예약한 뒤의 수업과 수강권을 같은 모양으로 돌려줍니다. 실패(`500`)는 화면에서 재현되지 않고 테스트에서 확인합니다.

## 주는 것

| 파일               | 내용                                           |
| ------------------ | ---------------------------------------------- |
| `ClassDetail.tsx`  | 수업 예약 화면. 오늘 바꿀 곳                   |
| `ClassSummary.tsx` | 수업 이름·일시·장소. 전에 누군가 먼저 빼 둔 것 |

| `time.ts`          | `formatDateTime`, `formatMonthDay`             |
| `handlers.ts`      | 모의 서버                                      |
| `Problem.spec.tsx` | 행동 테스트. 지금 모두 통과합니다              |

## 할 일

1. **고치기 전에** `ClassDetail`의 화면 부분을 위에서부터 읽으며 `note.md`의 첫 질문에 답합니다.
2. 화면 동작은 그대로 두고, `ClassDetail`을 위에서부터 읽을 때 한 높이로 읽히게 바꿉니다. 파일을 나눌지, 같은 파일 안 함수로 둘지, `ClassSummary`를 그대로 쓸지는 직접 정합니다. `Problem.spec.tsx`는 고치지 않고 그대로 통과해야 합니다.
3. `pnpm dev`로 띄워 375px 너비에서 수강권을 바꾸고 예약해 봅니다.
4. `note.md`의 나머지 질문에 답합니다.
