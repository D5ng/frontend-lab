# 상품 카드의 boolean props 정리하기

- 역할: 리마인드 · 15~20분
- 유형: 리팩터링. 동작하는 시작 코드와 이미 통과하는 테스트가 있습니다.
- 도메인: 커머스 (장보기 앱의 상품 카드)
- 화면 없음. 컴포넌트와 테스트만 있어서 앱 목록에는 나오지 않습니다.

```bash
pnpm --filter @frontend-lab/drills test problems/2026-11-01-compose-variants/problem-1
```

## 상황

장보기 앱의 상품 카드 `ProductCard`는 세 곳에서 씁니다. 모두 `ProductSections.tsx`에 있습니다.

| 어디                                | 컴포넌트              | 보여 주는 것                                 |
| ----------------------------------- | --------------------- | -------------------------------------------- |
| 홈 · 많이 산 상품                   | `BestSellers`         | 사진 위에 순위와 품절, 할인한 가격           |
| 검색 결과                           | `SearchResults`       | 사진 위에 품절, 할인한 가격, `장바구니 담기` |
| 장바구니 아래 · 함께 사면 좋은 상품 | `CartRecommendations` | 사진 없이 작게, 할인한 가격, 짧은 `담기`     |

처음에는 검색 결과용 카드 하나였습니다. 홈에 순위가 붙으면서 `showRank`와 `rank`가, 장바구니 추천이 생기면서 `compact`가 들어왔습니다. 지금은 props가 여덟 개입니다.

어디서 쓰든 지켜야 하는 규칙도 있습니다.

- 할인율이 있으면 할인율, 할인한 가격, 원래 가격을 함께 보여 줍니다. 할인한 가격은 10원 아래를 버립니다.
- 다 팔린 상품은 담을 수 없습니다.

## 할 일

1. 세 곳의 화면은 그대로 두고, `ProductCard`가 변형마다 boolean prop을 하나씩 받지 않게 바꿉니다. `ProductCard.spec.tsx`는 고치지 않고 그대로 통과해야 합니다.
2. 무엇을 카드가 맡고, 무엇을 쓰는 쪽이 채우게 했는지 `note.md`에 답합니다.
