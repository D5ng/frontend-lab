# 조합으로 변형 늘리기 (children, 슬롯)

읽기 5분. 오늘 세 문제는 모두 이 기법 하나만 씁니다.

## 개념

화면을 만들다 보면 **거의 같은데 조금씩 다른 조각**이 생깁니다. 상품 카드가 홈에서는 순위를 달고, 검색에서는 담기 버튼을 달고, 장바구니에서는 작게 나옵니다. 이런 것을 **변형**이라고 부릅니다.

변형을 늘리는 방법은 크게 둘입니다.

- **설정으로 고른다**: 컴포넌트가 모든 변형을 알고, 쓰는 쪽은 `showRank`, `compact` 같은 props로 어느 것을 켤지 고릅니다.
- **조합으로 채운다**: 컴포넌트는 늘 같은 **틀**만 맡고, 변형마다 다른 자리를 비워 둡니다. 쓰는 쪽이 그 자리를 채웁니다.

이 기법은 두 번째입니다. 빈 자리를 만드는 방법은 셋입니다.

| 방법           | 모양                                    | 언제                                |
| -------------- | --------------------------------------- | ----------------------------------- |
| `children`     | `<Card>여기에 무엇이든</Card>`          | 빈 자리가 하나일 때                 |
| 이름 붙은 슬롯 | `<Card thumbnail={...} footer={...} />` | 빈 자리가 여럿이고 위치가 정해질 때 |
| 하위 컴포넌트  | `<Card><Card.Thumbnail />…</Card>`      | 자리 여럿을 쓰는 쪽이 골라 넣을 때  |

SEED의 `ListItem`이 좋은 예입니다. `prefix`, `title`, `detail`, `suffix` 자리만 정해 두고 무엇을 넣을지는 묻지 않습니다. 그래서 프로필 사진도, 아이콘도, 스위치도 같은 `ListItem`에 들어갑니다.

사람의 말로 바꾸면 이 질문입니다.

> "변형이 하나 더 생기면, 지금 잘 돌고 있는 컴포넌트를 열어야 하나?"

> "이 boolean props 두 개를 같이 켜면 무슨 화면이 나오지?"

## 낮을 때 보이는 신호

- `showX`, `isY`, `withZ` 같은 boolean props가 **변형이 생길 때마다 하나씩** 늘어난다.
- props끼리 짝을 맞춰야 뜻이 있다. `showRank`를 켜면 `rank`도 줘야 하고, `showCartButton`을 켜면 `onAddToCart`도 줘야 한다. 하나만 주면 조용히 안 보인다.
- 한 곳에서만 쓰는 prop이 공통 컴포넌트에 있다. 그 화면의 요구가 바뀌면 다른 화면이 같이 쓰는 파일을 연다.
- JSX 여러 자리에 `type === 'a' ? … : type === 'b' ? …`가 반복된다. 변형 하나를 더하면 자리마다 분기를 하나씩 더한다.

## 흔한 오해 두 가지

1. **"조합이 좋으니 전부 열어 둔다."** 틀이 지켜야 할 것까지 쓰는 쪽에 넘기면 쓰는 곳마다 다르게 지켜집니다. "품절이면 담을 수 없다", "읽지 않은 알림은 표시한다", "이름과 시각의 간격"처럼 **어디서 쓰든 같아야 하는 것은 틀이 지킵니다.** 열어 두는 것은 실제로 변형마다 다른 자리뿐입니다. 모든 자리가 `ReactNode`인 컴포넌트는 그냥 `div`와 다르지 않습니다.
2. **"boolean prop은 모두 나쁘다."** `disabled`, `selected`처럼 **상태 하나를 켜고 끄는** prop은 괜찮습니다. 냄새가 나는 것은 "어떤 조각을 보여 줄지"를 boolean으로 고를 때입니다. 조각이 늘면 boolean도 같이 늘고, 켤 수 있는 조합이 곱으로 늘어납니다.

더 읽을거리: React 공식 문서, [Passing JSX as children](https://react.dev/learn/passing-props-to-a-component#passing-jsx-as-children)

## 용어집

| 뜻                         | 영어                                    |
| -------------------------- | --------------------------------------- |
| 변형                       | `variant`                               |
| 틀 / 빈 자리               | `layout`, `frame` / `slot`              |
| 앞 / 본문 / 뒤 / 아래 자리 | `prefix` / `body` / `suffix` / `footer` |
| 상품 카드                  | `ProductCard`                           |
| 썸네일 / 순위              | `thumbnail` / `rank`                    |
| 할인율 / 할인한 가격       | `discountRate` / `salePrice`            |
| 품절                       | `soldOut`                               |
| 장바구니 담기              | `addToCart`                             |
| 알림 / 알림함              | `notification` / `inbox`                |
| 읽지 않음                  | `unread`                                |
| 댓글 / 좋아요              | `comment` / `like`                      |
| 좋아요 누른 사람들         | `likers`, `actors`                      |
| 모임 / 모임 초대           | `group` / `invite`                      |
| 초대한 사람                | `inviter`                               |
| 참여하기 / 거절            | `accept` / `decline`                    |
| 초대에 답하다              | `answerInvite`, `respondToInvite`       |
| 일정이 바뀜                | `scheduleChanged`                       |
| 몇 분 전                   | `timeAgo`, `relativeTime`               |
