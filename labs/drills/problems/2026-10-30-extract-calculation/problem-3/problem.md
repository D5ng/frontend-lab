# 변경 요청: 자동이체 우대 금리

- 역할: 확인 · 20~30분
- 유형: 변경 요청. 문제 2에서 바꾼 코드 위에 구현합니다.
- 도메인: 금융 (적금, 문제 2 이어서)
- SEED: 문제 2에 `Checkbox` 추가 (`seed-design/ui/checkbox`)

## 요청

> 상품 기획: "자동이체로 넣으시는 분께 연 0.5%p를 더 드리기로 했어요. 계산기에서 자동이체로 넣기를 체크하면 금리와 만기 금액이 바로 바뀌게 해 주세요. 기간별 비교와 가입 확인에도 같은 금리로 보여 주시고, 가입 확인의 금리 옆에는 '자동이체 우대 0.5%p 포함'이라고 적어 주세요. 가입 요청에도 자동이체 여부를 같이 보내 주세요."

- 우대 금리는 모든 기간에 똑같이 연 0.5%p입니다. 서버 상품 응답은 바뀌지 않습니다.
- 체크박스는 기간 아래에 두고, 이름에 "자동이체"가 들어가게 합니다. 가입하기를 눌러야 반영되는 폼 안의 항목이라 `Switch`가 아니라 `Checkbox`입니다.
- 계산기의 금리 표시(`연 3.5% · 단리`)는 우대를 더한 금리로 바뀝니다.
- 가입 요청 본문에 `autoTransfer`를 더합니다.

```http
POST /api/drills/2026-10-30/savings/accounts
{ "productId": "monthly-1", "monthlyAmount": 300000, "months": 12, "autoTransfer": true }
```

예: 매달 300,000원, 12개월에 자동이체를 체크하면 연 4.0%가 되어 세전 이자 78,000원, 세금 12,012원, 만기에 받는 돈 3,665,988원입니다.
