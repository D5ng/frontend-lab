# 계산 규칙을 컴포넌트 밖 순수 함수로 꺼내기

읽기 5분. 오늘 세 문제는 모두 이 기법 하나만 씁니다.

## 개념

**계산 규칙**은 기획이나 정책이 "이렇게 계산해요"라고 정해 둔 것입니다. 적금 이자, 주차 요금, 배달팁처럼 입력이 정해지면 결과가 하나로 정해집니다.

**순수 함수**는 같은 값을 넣으면 언제 불러도 같은 값을 돌려주고, 부른 뒤에 바깥에 바뀐 것이 없는 함수입니다.

이 기법은 렌더링 중, 이벤트 핸들러, effect 안에 섞여 있는 계산 규칙을 **필요한 값을 모두 인자로 받는 순수 함수**로 꺼내는 것입니다. 컴포넌트는 그 함수를 부르고 결과를 보여 주기만 합니다.

사람의 말로 바꾸면 이 질문입니다.

> "이 금액이 맞는지 확인하려면 화면을 띄워야 하나?"

화면을 띄우고, 입력하고, 버튼을 눌러야만 확인할 수 있다면 계산이 화면에 묶여 있는 것입니다.

### 순수한지 알아보는 두 질문

1. **같은 값을 넣으면 언제 불러도 같은 값이 나오나?** 안에서 `Date.now()`, `Math.random()`, 바깥 변수, state를 직접 읽으면 아닙니다. 그 값은 인자로 받습니다.
2. **부르고 나서 바뀐 것이 있나?** 인자로 받은 객체를 고치거나, 저장·요청·로그를 하면 아닙니다. 그 일은 부르는 쪽이 합니다.

## 낮을 때 보이는 신호

- 같은 계산식이 여러 컴포넌트에 복사되어 있다. 한 화면은 이자를, 다른 화면은 만기 금액만 쓰느라 모양이 조금씩 다르다.
- 계산이 맞는지 보려고 테스트가 화면을 띄우고 입력하고 버튼을 누른다.
- 계산 안에서 지금 시각이나 state를 직접 읽어서, "10분 뒤엔 얼마?", "24개월이면 얼마?"처럼 **다른 값을 넣어 물어볼 수 없다.**
- 핸들러 하나에 계산·저장·화면 이동이 섞여 있어서, 계산만 다시 쓰려 해도 저장이 따라온다.

## 흔한 오해 두 가지

1. **"컴포넌트 파일 밖으로 옮기면 순수 함수다."** 아닙니다. 옮긴 함수 안에서 `Date.now()`를 부르거나 인자 객체를 고치면 여전히 순수하지 않습니다. 위치가 아니라 위의 두 질문으로 판단합니다.
2. **"계산처럼 보이면 전부 꺼낸다."** `amount.toLocaleString()`, `items.length > 0`, 버튼 문구 조립까지 꺼내면 컴포넌트를 읽을 때 파일을 오가야 합니다. 꺼낼 것은 기획이 정한 규칙(금리, 세금, 요금 구간)이고, 화면에 어떻게 보일지(쉼표, 문구)는 화면에 두어도 됩니다. 기준은 "이 규칙을 화면 없이 설명하고 확인할 이유가 있는가"입니다.

## 용어집

| 뜻                      | 영어                              |
| ----------------------- | --------------------------------- |
| 계산하다                | `calculate`                       |
| 매달 넣는 돈            | `monthlyAmount`                   |
| 기간 (개월)             | `months`, `term`                  |
| 연 금리                 | `annualRate`                      |
| 넣는 돈 합계 (원금)     | `principal`                       |
| 세전 이자               | `interest`, `grossInterest`       |
| 이자에 붙는 세금        | `tax`, `interestTax`              |
| 세후 이자               | `netInterest`, `afterTaxInterest` |
| 만기에 받는 돈          | `maturityAmount`                  |
| 우대 금리               | `bonusRate`, `preferentialRate`   |
| 자동이체                | `autoTransfer`                    |
| 주차 요금               | `parkingFee`                      |
| 무료 시간               | `freeMinutes`                     |
| 하루 최대 요금          | `dailyMaxFee`                     |
| 출차 정산               | `checkout`                        |
| 미리 보여 준 금액(견적) | `quote`, `quotedFee`              |
| 머문 시간               | `parkedMinutes`, `duration`       |
| 지금 시각               | `now`                             |
