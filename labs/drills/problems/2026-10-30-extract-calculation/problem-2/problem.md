- 도메인: 금융 (적금)
- SEED: `TextField`, `SegmentedControl`, `BottomSheet` + `ListButtonItem`, `Callout`, `Skeleton`, `ActionButton`

```bash
pnpm dev
pnpm --filter @frontend-lab/drills test problems/2026-10-30-extract-calculation
```

## 화면

> 매달 얼마씩 몇 개월 넣으면 만기에 얼마를 받는지 보고, 마음에 드는 기간으로 적금에 가입한다.

```text
적금 계산하기 ──▶ 가입 내용 확인 ──▶ 가입 완료
  └─ 기간별로 비교하기 (바텀시트)
```

- 기간은 세 개뿐이라 시트 없이 `SegmentedControl`로 바로 고릅니다.
- 기간별 비교는 값 하나를 고르는 일이고 닫아도 잃을 것이 없어서 바텀시트로 띄웁니다. 고르면 그 기간으로 바뀌고 시트가 닫힙니다.
- 가입은 매달 돈이 빠져나가는 결정이라, 보여 줄 금액을 한 화면에 모아 한 번 더 확인합니다.

| 상태     | 보여 주는 것                                                                 |
| -------- | ---------------------------------------------------------------------------- |
| 불러오기 | 상품 정보 자리에 `Skeleton`                                                  |
| 실패     | 불러오기 실패는 `Callout`과 다시 불러오기, 가입 실패는 확인 화면에 `Callout` |
| 빈 상태  | 금액을 넣기 전에는 무엇을 넣으면 되는지 한 줄                                |
| 비활성   | 금액이 없거나 범위를 벗어나면 가입하기를 누를 수 없고 필드에 이유            |
| 성공     | 가입 완료 화면                                                               |

## 계산 규칙

은행이 정한 규칙입니다. 이 상품은 단리 적금이라, 매달 넣은 돈마다 만기까지 남은 개월 수만큼 이자가 붙습니다.

- **세전 이자** = 매달 넣는 돈 × (연 금리 ÷ 100 ÷ 12) × (1 + 2 + … + 개월 수). 원 단위 아래는 버립니다.
- **세금** = 세전 이자의 15.4%. 원 단위 아래는 버립니다.
- **만기에 받는 돈** = 넣는 돈 합계 + 세전 이자 − 세금

예: 매달 300,000원, 12개월, 연 3.5%면 세전 이자 68,250원, 세금 10,510원, 만기에 받는 돈 3,657,740원입니다.

## 모의 API

모의 서버(`handlers.ts`)는 풀이 대상이 아닙니다.

```http
GET /api/drills/2026-10-30/savings/products/monthly-1
```

```json
{
  "id": "monthly-1",
  "name": "매달 모으는 적금",
  "minMonthlyAmount": 10000,
  "maxMonthlyAmount": 500000,
  "terms": [
    { "months": 6, "annualRate": 3.0 },
    { "months": 12, "annualRate": 3.5 },
    { "months": 24, "annualRate": 4.0 }
  ]
}
```

```http
POST /api/drills/2026-10-30/savings/accounts
{ "productId": "monthly-1", "monthlyAmount": 300000, "months": 12 }
```

`201 { "id": "sv-1001" }`이면 가입 완료입니다. 실패(`500`)는 화면에서 재현되지 않고 테스트에서 확인합니다.
